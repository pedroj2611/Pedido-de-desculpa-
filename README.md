# Pedido de Desculpa Especial para Meu Amorzinho ❤️

Um aplicativo web interativo, moderno e romântico no formato **PWA (Progressive Web App)**, feito especialmente para pedir desculpas de forma carinhosa, divertida e inesquecível.

---

## ✨ Funcionalidades

- 📱 **100% Responsivo e Otimizado para Celular (PWA)**:
  - Pode ser instalado na tela inicial do celular como um aplicativo nativo.
  - Suporte offline completo através de Service Worker.
- 🏃💨 **Botão "Não" Fujão**:
  - Ao passar o mouse (no computador) ou tentar tocar na tela (no celular), o botão foge instantaneamente para um local seguro da tela.
- 🎯 **Regra das 5 Tentativas**:
  - A cada tentativa, frases engraçadas e carinhosas aparecem.
  - Ao passar de 5 tentativas de apertar o "Não", o botão desaparece em uma animação mágica (*poof*), deixando apenas a opção **"Sim"** disponível e destacada!
- 🎆💖 **Celebração com Show de Fogos e Corações**:
  - Ao clicar em **"Sim"**, um show de fogos de artifício com formatos de corações e partículas brilhantes ilumina a tela com animações em Canvas.
  - A mensagem emocionante **"EU TE AMO AMORZINHO!"** se destaca junto a uma linda declaração de amor e reconciliação.
  - Efeitos sonoros suaves sintetizados diretamente no navegador via Web Audio API.

## 🚀 Como Ativar no GitHub Pages para Compartilhar

Para que sua namorada possa abrir o site diretamente pelo link no celular:

1. Acesse o repositório no GitHub: [https://github.com/pedroj2611/Pedido-de-desculpa-](https://github.com/pedroj2611/Pedido-de-desculpa-)
2. Clique na aba **Settings** (Configurações) no topo.
3. No menu lateral esquerdo, clique em **Pages**.
4. Em **Build and deployment** > **Branch**:
   - Selecione a branch: `main`
   - Selecione a pasta: `/(root)`
   - Clique em **Save**.
5. Aguarde cerca de 1 a 2 minutos e o link público estará pronto:
   👉 **`https://pedroj2611.github.io/Pedido-de-desculpa-/`**

## 💻 Tecnologias Utilizadas

- **HTML5 Semântico**
- **CSS3 Moderno** (Glassmorphism, Flexbox, Animações e Variáveis)
- **JavaScript ES6+** (Touch & Pointer Events, Lógica de Viewport, Web Audio API)
- **HTML5 Canvas** (Motor de partículas e fogos de artifício sem dependências)
- **PWA** (Manifest.json + Service Worker para suporte offline e instalação móvel)
